# Послание кодеру simplex-rs — 2026-11-18 (после свежего прогона истории v0.71–v0.90)

Состояние: v0.90, ~5260 строк src/, suite 70/70 + strict 3/3, clippy 0, PQDR default-on,
SEC-01 negative MITM test зелёный, live interop SMP v17..v23 + XFTP v4 OK. Хорошая база.

## Что не хватает (по приоритету)

1. **onion over SMP proxy chains** (roadmap #4, stated platform goal) — `src/onion.rs`
   сейчас только один hop (`onion_request`); нужны multi-hop цепочки через несколько
   релеев с per-hop шифрованием, как в SMP spec (2-hop уже в протоколе — у вас клиентская сторона?).
2. **sessionId ↔ TLS 1.3 Finished** (roadmap #1) — сейчас rustls exporter, надо сверять с
   реальным verify_data, иначе channel binding слабее, чем в spec.
3. **NTF live-прогон** против публичных NTF-серверов (roadmap #2) — push сейчас только локально.
4. **Чистка unwrap/expect**: sb_chain 16, ffi 8, pqdr 3, transport 3, client 2, store 1, server 1.
   FFI уже под catch_unwind, но в sb_chain паника = потеря цепочки. Цель: 0 unwrap в src,
   кроме тестов.
5. **Async engine с auto-reconnect** поверх async_client.rs (roadmap #5) — сейчас reconnect
   ручной; для мобильного клиента нужен backoff-цикл как в NeXX chat_worker.
6. **PQDR: willkommen** — ratchet default-on уже хорошо; что осталось: key rotation расписание,
   skipped-message limits (reorder window), и snapshot/restore уже есть — проверьте против spec pqdr.md.
7. **Внешний аудит** (roadmap #6): docs/AUDIT-PROMPT.md уже лежит — запустите critic по 3 зонам.

## Рекомендации по практике

- Держите probe-бины (`smp-v71`, `xftp-h2-v71`) строго за feature-флагом и NoVerify — ок, но
  добавьте в CI ассерт, что дефолтная сборка не линкует их (иначе легко утечёт в релиз).
- `send_only` ACK pattern (v0.88) — правильно; распространите на все пути доставки MSG.
- Store fail-closed уже есть; добавьте миграции версий сторa с rollback-тестом.
- Для interop: держите `scripts/` harnesses — они уже ловят pad-overflow регрессии; добавьте
  XFTP chunked >64KB roundtrip в live-набор (сейчас PING/PONG only).
- Документация: SECURITY.md синхронизирован (v0.83) — обновите после закрытия пунктов 1–3.
