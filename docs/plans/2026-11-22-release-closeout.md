## Часть B — зависит от владельца (нужно от вас)

### B1. Внешний аудит (G7) — **главный блокер релиза**

Что уже готово: `docs/AUDITOR-LETTER.md` (обновлюю в A8), `docs/RELEASE-READINESS.md`,
`docs/SECURITY.md`, клон `simplexmq/` и спецификации `spec/` — всё в репозитории.

1. Выберите аудитора: 1–2 человека с опытом Rust+криптографии **или** Haskell/SimpleX.
2. Дайте read-доступ к `https://github.com/PerfectFriend/RustSimplex` (приватный репозиторий) —
   пригласить как collaborator с правом «Read» достаточно.
3. Отправьте письмо из `docs/AUDITOR-LETTER.md` + ссылку на `docs/RELEASE-READINESS.md`.
4. Зафиксируйте срок (предлагаю **5 рабочих дней** до даты релиза).
5. **Пришлите мне отчёт** — я разберу находки, починю критичные и обновлю readiness.

Зоны аудита (из письма): криптография (`src/crypto.rs`), wire-форматы
(`encoding/protocol/transport`), аутентификация (Ed25519/X25519/pinning), PQDR (`src/pq*.rs`),
известные ограничения (`docs/SECURITY.md`).

### B2. Публикация v0.99.1 на crates.io (G8)

Нужен ваш аккаунт и один секрет. **Ключи в чат не присылайте** — только в GitHub Secrets.

1. Проверьте, что имя свободно: <https://crates.io/api/v1/crates/smp-rs> → должен быть `404`/`not_found`.
2. Зарегистрируйтесь на crates.io, включите 2FA.
3. Создайте токен со scope **Publish** → GitHub: репозиторий → Settings → Secrets and variables →
   Actions → New repository secret → имя **`CARGO_REGISTRY_TOKEN`** → значение токена.
4. Напишите мне: «токен в секретах, имя свободно» — я прогоню `cargo publish --dry-run`,
   проверю метаданные/лицензию/описание и подготовлю релиз.
5. Тег: я подготовлю `v0.99.1` (версия в `Cargo.toml` уже `0.99.1`), пуш тега — по вашей команде
   («можно тегать»).
6. Пайплайн `release.yml` сам соберёт changelog, опубликует на crates.io и создаст GitHub Release.

### B3. Решение о релизе

Ответьте по трём пунктам (можно одной строкой):
- **Версия**: рекомендую `v0.99.1` (не `1.0.0`: не закрыты FFI-smoke в CI и auto-reconnect у async-клиента);
- **Дата**: после сдачи B1 (иначе выпускаем как `0.99.1` с честным «beta»);
- **Канал**: crates.io + GitHub Release (без отдельной подписки).

### B4. Android-потребитель (Paranoid)

Моя часть готова: `libsmp_rs.so` собирается (`crate-type = cdylib`), uniffi-биндинги для Kotlin
генерируются офлайн, `ffi-smoke` есть. От вас:
- собрать `.so` под вашу архитектуру (`--features ffi --release`, NDK вашей версии);
- подключить `kotlin/uniffi/smp_rs/` к приложению Paranoid;
- сказать, какой API Paranoid реально зовёт (`create_contact`, `send_message`, …) — я добавлю
  недостающие функции в фасад и обновлю smoke-тест.

### B5. Настоящий мобильный клиент SimpleX (для интероперабельности)

Нужен реальный аккаунт/телефон SimpleX (в тестах — self-chat «я → я»). Я готовлю скрипт (A9);
от вас: одноразовый запуск по инструкции и присланный лог.

### B6. Личные NTF-токены (живой критерий G1)

Публичный NTF-сервер не выдаёт токены сторонним клиентам — это не баг, а политика сервера.
Чтобы закрыть G1 «по-настоящему», нужен ваш NTF-сервер (личный аккаунт SimpleX) с выданным токеном.
Дайте токен через переменную окружения (не в чат): `SMP_NTF_TOKEN` — я добавлю live-проверку
подписанных `TNEW`/`SNEW` против вашего сервера.
